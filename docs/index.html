Choose your board and install the firmware.

Select the card that matches your ESP board and hardware revision. Check the wiring table carefully before flashing. Each card installs a firmware image compiled for its listed GPIO configuration.

!
Select the correct hardware configuration. The two ESP32-C3 firmware variants use different BUSY and MOD pins. Installing the wrong variant will prevent the BC7215 module from working correctly.
Configuration 1

ESP32-C3 XIAO / ESP32-C3 Super Mini

Firmware for the current ESP32-C3 GPIO configuration.

Pin connections

Connect the BC7215 module as shown below.

BC7215 signal ESP GPIO
BC7215 TXGPIO4
BC7215 RXGPIO3
BC7215 BUSYGPIO5
BC7215 MODGPIO6

Also connect BC7215 GND to GND and VCC to 3.3V.

After installation

Configure Wi-Fi and add the device

After flashing, complete the ESPHome setup and pair the BC7215 controller with your air-conditioner remote.

  1. Configure Wi-Fi when prompted by the installer.
  2. Open Home Assistant.
  3. Go to Settings → Devices & services.
  4. Add the discovered ESPHome device.
  5. Set the IR remote to 25°C / Cooling mode.
  6. Open the device page and click Pair Button.
  7. Press Fan Speed on the remote to finish pairing.
